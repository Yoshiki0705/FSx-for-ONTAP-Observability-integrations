# パイプライン検証環境

🌐 **日本語**(このページ) | [English](../en/README.md)

## 概要

5 つのリアルタイムテレメトリパイプラインパターンに対する、再現可能かつ CI 検証可能なテスト環境と検証記録。このバイリンガル入口はトップレベルの [README](../../README.md) のミラーであり、再利用マップと段階順の詳細はそちらにある。

## 2 つの提供層

CI 検証可能な足場層(段階 0)はライブ AWS アカウント不要・課金なし。サンプル実行検証層は稼働中の FSx for ONTAP ファイルシステムを要し、課金され、不可逆リソースに触れ、CI では実行しない。

## 段階実装順

優先度は net-new 価値に従う。P2 → P5 → P4 → P1 とし、パターン 3 は再利用と記録のみ。

## 再利用マップ

再利用参照と net-new 宣言は [`shared/reuse-references.yaml`](../../shared/reuse-references.yaml) にあり、Duplication_Check ゲートの唯一の入力となる。

## スコープ境界

検証環境と検証記録のみ。本番グレードデプロイ、マルチリージョン HA、サンプル実行を超える負荷/スケールベンチマークは、明示的に追求する場合を除きスコープ外。
